# 🌍 ClimateScope – Global Weather Analytics & Visualization

---

## 📌 Overview

ClimateScope is a data analytics and visualization project focused on analyzing large-scale global weather datasets to identify climate patterns, environmental trends, and extreme weather conditions. The project demonstrates an end-to-end workflow involving data preprocessing, exploratory data analysis, statistical interpretation, and interactive dashboard visualization using Python and Power BI.

The project processes over **124,000+ global weather records** to generate meaningful climate insights and visualize regional weather variability across different geographical locations.

---

## 🎯 Project Objectives

- Clean and preprocess large-scale weather datasets
- Perform exploratory and statistical weather analysis
- Detect climate anomalies and unusual weather behavior
- Analyze correlations between environmental parameters
- Visualize global climate trends using Power BI dashboards
- Generate actionable insights from weather data

## ▶️ How to Run the Project

1. Open the Jupyter notebooks:
   - `data_preprocessing.ipynb`
   - `core_weather_analysis.ipynb`

2. Run the preprocessing notebook to clean and prepare the dataset.

3. Run the analysis notebook to generate weather insights and visualizations.

4. Open `ClimateScope_Dashboard.pbix` in Power BI Desktop to explore the interactive dashboard.
