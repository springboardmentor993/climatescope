# 🌦️ ClimateScope Project

## 📌 Project Overview

ClimateScope is a weather data analysis project that focuses on understanding climate patterns using data processing, visualization, and dashboarding techniques. The project demonstrates an end-to-end workflow from raw data cleaning to interactive dashboard creation.

---

## 📊 Features

* Data cleaning and preprocessing of weather dataset
* Exploratory Data Analysis (EDA)
* Visualization of key weather parameters (Temperature, Humidity, Visibility)
* Interactive Power BI dashboard
* Insights generation from weather trends

---

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* Power BI
* Jupyter Notebook
* GitHub

---

## 📁 Project Structure

* `Data_cleaning.ipynb` → Data preprocessing and cleaning
* `Data_Visualization.ipynb` → Data analysis and visualization
* `Processes_data.ipynb` → Initial data processing
* `clean_data.csv` → Final cleaned dataset
* `dashboard.pbix` → Power BI dashboard file
* `design documentation.pdf` → Project design details

## 🔍 Key Insights

* Temperature and humidity show noticeable correlation
* Visibility decreases during high humidity conditions
* Weather patterns vary across different time periods
* Seasonal trends can be observed in temperature changes

---

## ▶️ How to Use

1. Open Jupyter Notebook
2. Run `Data_cleaning.ipynb` for preprocessing
3. Run `Data_Visualization.ipynb` for analysis
4. Open `dashboard.pbix` in Power BI to view the dashboard
