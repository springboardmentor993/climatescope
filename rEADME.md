## 🚀 Project Overview

A **3-page interactive Power BI dashboard** designed to analyze:

* 🌡 Temperature trends
* 💨 Wind patterns
* 🌧 Rainfall distribution
* 🌫 Air quality insights

✨ Built using **data storytelling + visual analytics**
